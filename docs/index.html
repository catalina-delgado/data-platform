Documentación de StrategoData

Guías para integrar con la API pública y para usar strategodata_client desde Python. Para la documentación de tablas de cada proyecto (esquema y significado de columnas por dataset), ver docs/<proyecto>/ — este índice cubre la plataforma en sí, no los datos de un proyecto en particular.

  • Cómo empezar — conseguir una API key y hacer la primera llamada.
  • Integración (API REST) — referencia completa de endpoints, autenticación, planes y límites.
  • Cliente Python (strategodata_client) — instalación, uso y diferencias con la versión anterior basada en Iceberg.
  • Manejo de errores — códigos HTTP, formato de error, y cómo reaccionar ante rate limit / cuota excedida.

Para la arquitectura general de la plataforma (capas bronze/silver/gold, componentes, despliegue), ver el README.md del repo.
