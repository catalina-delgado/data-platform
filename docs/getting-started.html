Cómo empezar

1. Conseguir una API key

Hoy las API keys se emiten a mano desde el equipo de StrategoData (todavía no hay un flujo de alta self-service — ver roadmap). Cada key tiene un plan asociado que define su límite de tasa y su cuota mensual:

Plan Límite de tasa Cuota mensual Lectura Escritura
free 60 req/min 10.000 sí no
pro 600 req/min 1.000.000 sí no
internal 6.000 req/min sin límite sí sí

Solo las keys de plan internal pueden escribir — están pensadas para los pipelines propios de StrategoData (jobs de Airflow), no para consumidores externos. Ver manejo de errores si una key de otro plan intenta escribir.

Si administrás la plataforma, las keys se crean con:

docker exec strategodata-api python manage_keys.py create "Nombre del cliente" --plan pro

Esto imprime la key en texto plano una sola vez — en la base solo se guarda su hash (SHA-256), así que si se pierde hay que crear una nueva.

2. Hacer la primera llamada

Con la key en mano, cualquier request necesita el header X-API-Key:

curl -H "X-API-Key: TU_API_KEY" \
  https://api.strategodata.io/v1/namespaces

{ "namespaces": ["bronze", "silver", "gold"] }

Si la respuesta es 401, revisar manejo de errores.

3. Leer una tabla

curl -H "X-API-Key: TU_API_KEY" \
  "https://api.strategodata.io/v1/tables/gold/resumen_diario_por_clase?limit=10"

{
  "table": "gold.resumen_diario_por_clase",
  "row_count": 2,
  "records": [
    { "clase": "probiotico", "fecha": "2026-06-01", "total_muestras": 1, "score_promedio": 0.82 },
    { "clase": "no_probiotico", "fecha": "2026-06-01", "total_muestras": 1, "score_promedio": 0.15 }
  ]
}

4. Revisar el consumo

Cada key puede consultar su propio uso en cualquier momento:

curl -H "X-API-Key: TU_API_KEY" https://api.strategodata.io/v1/usage

{
  "key_name": "Cliente Alpina",
  "plan": "pro",
  "rate_limit_per_minute": 600,
  "monthly_quota": 1000000,
  "requests_today": 42,
  "requests_this_month": 8213
}
