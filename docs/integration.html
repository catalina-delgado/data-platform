Integración (API REST)

Base URL local: http://localhost:8000. En producción, la que te haya dado el equipo de StrategoData (ej. https://api.strategodata.io).

Los endpoints de datos están versionados bajo /v1 — es la única versión que existe hoy; si en el futuro hay cambios incompatibles, se sumará /v2 sin romper /v1. / y /health no están versionados porque describen la API en sí, no los datos.

Autenticación

Todas las rutas bajo /v1 requieren el header X-API-Key:

X-API-Key: sk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

No hay OAuth, JWT ni sesiones — es un secreto único por consumidor. Guardarlo como cualquier credencial (variable de entorno, secret manager); no commitearlo. Ver cómo conseguir una key.

Planes y límites

Plan Límite de tasa Cuota mensual Lectura Escritura
free 60 req/min 10.000 sí no
pro 600 req/min 1.000.000 sí no
internal 6.000 req/min sin límite sí sí

El límite de tasa es una ventana fija de 60 segundos por key (no un token bucket): al pasarse, la API devuelve 429 hasta que empieza el minuto siguiente. La cuota mensual se resetea el día 1 de cada mes. Ver manejo de errores para cómo reaccionar.

Convención de capas

Todo dataset se nombra <capa>.<tabla>, ej. gold.resumen_diario_por_clase:

  • bronze: datos crudos, tal como llegan de la fuente.
  • silver: datos limpios, tipados y validados.
  • gold: datos agregados, listos para consumo — es la capa que la mayoría de los consumidores externos va a leer.

Endpoints

GET /

Sin autenticación. Info general de la API: planes disponibles, quickstart de endpoints, ejemplo de curl.

GET /health

Sin autenticación. Chequeo de salud para monitoreo ({"status": "ok"}).

GET /v1/namespaces

Lista las capas disponibles.

curl -H "X-API-Key: $KEY" https://api.strategodata.io/v1/namespaces

{ "namespaces": ["bronze", "silver", "gold"] }

GET /v1/namespaces/{namespace}/tables

Lista las tablas dentro de una capa.

curl -H "X-API-Key: $KEY" https://api.strategodata.io/v1/namespaces/gold/tables

{ "namespace": "gold", "tables": ["resumen_diario_por_clase"] }

GET /v1/tables/{namespace}/{table}

Lee una tabla y devuelve los registros en JSON.

Query param Tipo Default Descripción
limit int 1000 Máximo de filas a devolver. No es paginación real — para datasets grandes, usar strategodata_client en vez del endpoint HTTP. 
curl -H "X-API-Key: $KEY" \
  "https://api.strategodata.io/v1/tables/gold/resumen_diario_por_clase?limit=10"

{
  "table": "gold.resumen_diario_por_clase",
  "row_count": 2,
  "records": [ { "clase": "probiotico", "score_promedio": 0.82 } ]
}

POST /v1/tables/{namespace}/{table}

Escribe registros en una tabla (la crea si no existe). Reservado a keys de plan internal — ver 403 Forbidden.

Body:

{
  "records": [{ "id": 1, "clase": "probiotico", "score": 0.82 }],
  "mode": "overwrite",
  "partition_columns": ["fecha"]
}
Campo Tipo Default Descripción
records lista de objetos — Filas a escribir.
mode "append" | "overwrite" "append" append agrega archivos nuevos; overwrite reemplaza el dataset completo (ver nota de concurrencia).
partition_columns lista de strings null Columnas por las que particionar (Hive-style), opcional. 
curl -X POST -H "X-API-Key: $KEY" -H "Content-Type: application/json" \
  -d '{"records": [{"id": 1, "clase": "probiotico", "score": 0.82}], "mode": "overwrite"}' \
  https://api.strategodata.io/v1/tables/gold/prueba

{ "table": "gold.prueba", "rows_written": 1, "mode": "overwrite" }

Pensado para publicaciones puntuales de volumen moderado — para ingesta masiva, usar un job de Airflow con strategodata_client directamente.

GET /v1/tables/{namespace}/{table}/schema

Devuelve el esquema (columnas y tipos) de una tabla.

curl -H "X-API-Key: $KEY" \
  https://api.strategodata.io/v1/tables/gold/resumen_diario_por_clase/schema

{
  "table": "gold.resumen_diario_por_clase",
  "schema": { "clase": "large_string", "score_promedio": "double" }
}

GET /v1/usage

Uso de la key que hace la request, en lo que va del día y del mes, más su límite y cuota. Ver ejemplo completo.
